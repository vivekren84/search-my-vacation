# 30-Governance

## Purpose

This folder holds standing governance and operational definitions that apply across the release, rather than a single workstream's evidence trail:

- `Provider-Dependency-Register.md` — consolidated inventory of external providers the platform relies on.
- `External-Integration-Definition-of-Done.md` — the standard for when an external-provider integration is considered done.

## Note on the `30-` Prefix

A separate folder, `docs/30-Engineering/`, also exists under `docs/`, sharing the same `30-` numeric prefix. The two are unrelated in purpose despite the collision: `30-Engineering/` currently contains only an empty `Release-1.2/WS3/` directory tree — no files — and appears to be an earlier or superseded scaffold from Workstream 3's evidence-folder structuring; the actual Workstream 3 evidence it seems intended to hold lives instead under `docs/09-Development/Release-1.2/WS3/`.

No renaming or restructuring is performed by this note — it exists only so a reader encountering both `30-` folders understands the current state rather than assuming a broken or duplicated structure. Reconciling the numbering (either retiring the empty `30-Engineering/` tree or renumbering one of the two folders) is a small, low-risk housekeeping item recommended for after Release 1.2 closes, not decided here.
