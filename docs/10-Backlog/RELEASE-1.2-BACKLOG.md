# Vision

Release 1.2 builds upon the strong foundation established in Release 1.1.

The focus shifts from functional completeness to delivering a richer traveller experience through enhanced intelligence, storytelling, visual polish, performance, accessibility and personalization.

Release 1.2 is expected to prioritize depth over breadth, refining existing capabilities while introducing carefully selected new experiences that further differentiate Search My Vacation.

---

## Guiding Principle

Release 1.2 should focus on enhancing and deepening the traveller experience built in Release 1.1 rather than expanding functionality indiscriminately. Every new capability should improve trust, simplicity, personalization or business value while preserving the lightweight, premium experience established by previous releases.

# Release Principles

Release 1.2 should continue to prioritize:

- Traveller-first design
- Honest recommendations
- Simplicity over feature count
- Performance before complexity
- Trust before automation
- Measurable business value

---

# Candidate Success Metrics

- Increased Journey Passport completion
- Higher Traveller Story engagement
- Improved enquiry conversion
- Increased repeat visitor engagement
- Better mobile usability
- Faster page performance

---

# Out of Scope

The following items are intentionally not planned for Release 1.2 unless business priorities change:

- Native mobile applications
- Traveller login and account management
- Online booking and payment workflows
- Vendor portal
- CRM replacement
- Multi-language support
- Internationalisation
- Large-scale AI automation without explicit traveller control

These areas may be revisited in future releases based on business priorities.
